Koble til Sketchfab

Inne i en artifact kan ikke Sketchfab bygges inn som iframe, så her lastes modeller som filer. I Code Appen kan du enten bruke Sketchfab Viewer API (iframe) eller laste ned modellen som GLB og vise den i denne three.js-vieweren. Lim inn en modell-URL for å åpne den på Sketchfab.
